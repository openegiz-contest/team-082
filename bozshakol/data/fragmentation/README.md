Распределение получено модулем Fragmenter 2.0.0 (3GSM) по фотограмметрической модели развала. Используется как **эталон** для модели Kuz-Ram взрывов двойника (это другой карьер — сравниваются форма кривой и порядок величин, не абсолютный размер):

- измерено: x50 = 179.6 мм, x80 = 334.4 мм;
- Розин–Раммлер: n = 1.453 (ошибка подгонки 1.4 п.п.); Swebrec: b = 3.936;
- модель Kuz-Ram двойника принимает n = 1,35 — в пределах 0,1 от измеренного.

Подгонка — `ml/train.py` → `ml/models/fragmentation_ref.json`; показатели — в двойнике `drill-blast` (`frag_*`) и на дашборде «Открытые данные и ML».
