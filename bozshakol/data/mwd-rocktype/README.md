Статистики параметров бурения шпуров за цикл (проходка, давления вращения, подачи и ударника, расход воды — нормированные) и порода по картированию геолога; 10 пород.

Это **буровзрывная проходка тоннелей**, а не карьер: в двойнике данные **не выдаются за Бозшаколь**. Двойник `kz.bozshakol:mwd-01` проигрывает один реальный цикл за модельный час, только отложенные циклы (последние 25 % каждого тоннеля по пикетажу).

GBM-классификатор (`ml/models/mwd_rocktype.json`, 32 признака):
- точность на отложенных циклах 0.498 (macro-F1 0.403); «самая частая порода» — 0.233;
- порода прошлого цикла по картированию угадывает 0.948 — картирование надёжнее;
- на 63 сменах породы ML прав в 0.317 случаев (прошлый цикл — 0);
- как самостоятельная тревога «впереди смена породы» модель не годится: точность тревоги 0.068. Поэтому в двойнике это подсказка рядом с картированием, тревоги нет.
