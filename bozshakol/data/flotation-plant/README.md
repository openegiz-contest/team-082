Это реальная железорудная фабрика обратной флотации; в двойнике она **не выдаётся за Бозшаколь**. Двойник `kz.bozshakol:qc-01` («Анализатор качества флотации, реальные данные + ML») проигрывает одну реальную запись за каждый модельный час. Проигрывается только отложенная часть — последние 20 % времени, которые модель при обучении не видела.

ML-софтсенсор (`ml/models/flotation_silica.json`, GBM): оценивает SiO₂ в концентрате **сейчас** по 21 параметру процесса, их изменению за час и последнему анализу, который уже вернулся из лаборатории (задержка 3 ч).
- R² 0.372 против 0.244 у последнего анализа — модель лучше ловит крупные отклонения.
- Средняя ошибка (MAE) 0.687 против 0.679 п.п., на уровне наивного прогноза.
- Тест — 2017-08-06 21:00 … 2017-09-09 23:00.
