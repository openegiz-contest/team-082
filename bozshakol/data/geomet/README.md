## Как используется в двойнике

1. `ml/train.py` обучает GBM-интерполяцию Cu, Au, Fe, S, Al, K по координатам проб: перекрёстная проверка по скважинам, сравнение с обратными расстояниями (IDW). Затем считает 3D-сетку над карьером (`ml/models/geomet_grid.json`). Привязка: X, Y GeoMet = x, y двойника (м), Z GeoMet = 380 + 2·z двойника.
2. Ridge-модель по химии (`comminution.csv`) предсказывает индекс разрушаемости `t` (th3; больше — мягче руда). R² = 0.476 при перекрёстной проверке по скважинам.
3. У каждого нового взрывного блока (`sim/model.py`, `geomet_factors`) содержание Cu и Au и крепость (UCS, индекс Бонда) берутся из сетки и ML-модели. Множители нормированы на 1 вдоль забоя каждого экскаватора, поэтому уровень остаётся откалиброванным на Бозшаколь (S1), а изменения по мере продвижения забоя — из реальных скважин.
4. Извлечение `LCT` по химии **не предсказывается** (R² = -0.104), поэтому в модель не подключено; извлечение считает кинетическая модель флотации.

Качество интерполяции (R² по логарифму, перекрёстная проверка по скважинам): Cu 0.162 (IDW 0.038), Au 0.251 (IDW 0.119), Fe 0.316 (IDW 0.138), S 0.193 (IDW 0.083), Al 0.034 (IDW 0.0), K 0.164 (IDW 0.063). Пробы сильно варьируют от интервала к интервалу, поэтому R² невысокий; GBM стабильно лучше IDW.
