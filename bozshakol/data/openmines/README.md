Используется для сверки транспортного модуля: средняя скорость самосвала в OpenMines — 25 км/ч, в модели Бозшаколя — 21,8 км/ч на ходу (подъём 10 % по спиральному съезду гружёным); цикл экскавации крупной машины — 1,5 мин на ковш 20 т в OpenMines против ~0,6 мин на ковш 36 т у Hitachi EX3600; поток отказов дорог λ = 1/120 мин⁻¹ — в модели отказы дорог не моделируются (ограничение, см. SUBMISSION.md).
