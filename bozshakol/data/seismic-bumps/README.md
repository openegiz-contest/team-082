# seismic-bumps — сейсмическая опасность по сменам

| | |
|---|---|
| Источник | UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/266/seismic+bumps (Sikora M., Wróbel Ł., 2010) |
| Лицензия | CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/ |
| Файл | `seismic-bumps.arff` — 2584 смены, без изменений |

Данные подземной угольной шахты (Польша); в двойнике они **не выдаются за Бозшаколь**. Двойник `kz.bozshakol:sm-01` («Сейсмостанция, реальные данные + ML») проигрывает одну запись за модельную смену (12 ч), только последние 20 % смен, которые модель не видела.

GBM-классификатор (`ml/models/seismic_hazard.json`) оценивает вероятность опасной следующей смены (энергия толчков > 10⁴ Дж; таких смен 6.6 %).
- ROC AUC при перекрёстной проверке — 0.765 (экспертная оценка `ghazard` — 0.681).
- На будущих сменах ROC AUC — 0.604 (эксперт — 0.629): со временем качество падает. Поэтому в двойнике ML — вторая подсказка рядом с экспертной оценкой, а не замена ей.
- Порог тревоги — 0.108 (верхние 15 % вероятностей).
