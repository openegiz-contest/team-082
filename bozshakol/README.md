## Двойники и типы

Устройство повторяет платформу. Как в `examples/mine`, все двойники — прямые дети ГОК (`_parents = kz.bozshakol:site`), поэтому в OpenEgiz → Twins → ГОК → Children видна вся техника. Как в OpenTwins, у каждого двойника есть атрибут `type` со ссылкой на тип (`kz.bozshakol.types:haul-truck-cat-785c` и т. д.), а у типа `_parents = {"kz.bozshakol.types:site": N}`. Участок — обычный атрибут `section`.

```bash
cd bozshakol
python3 -m sim.export_twins          # пересобрать twins/*.json после изменения модели
python3 -m sim.export_twins --check  # убедиться, что файлы актуальны
```

## Поток данных

```
sim/main.py ──MQTT telemetry/<twin>──▶ Mosquitto ──▶ Ditto (состояние 113 двойников)
                                                      │  ├─▶ MQTT opentwins/# ─▶ Telegraf ─▶ InfluxDB ─▶ Grafana (11 дашбордов)
                                                      │  └─▶ REST ◀── 3D-пульт (nginx /ditto/ → ditto-nginx, чтение и запись сценария)
           ◀── REST GET kz.bozshakol:control ──────────┘
```

Модель никогда не пишет в InfluxDB напрямую. Пульт ничего не считает сам и показывает только то, что лежит в Ditto.

## Ключевые соотношения

- **Скорость самосвала:** `v = min(η·P/(m·g·(i+w)), v_max, лимит дороги, лимит сценария)`, на спуске груженым — 32 км/ч (тормоз-замедлитель). Сопротивление качению `w` = базовое + 1 % × увлажнение + до 6 % в дождь.
- **Топливо:** `л/ч = 18 + 0,26 × P_тяги[кВт]`.
- **Взрыв (Kuz-Ram):** `x50 = A · q^-0.8 · Q^(1/6) · (115/RWS)^(19/30)`, где `A = 3 + 0,05 · UCS`; `x80 = x50 · (ln5/ln2)^(1/n)`, n = 1,35. Сетка `B × S` подбирается из удельного расхода ВВ и вместимости заряда скважины.
- **Экскавация:** цикл = база × `(0,75 + 0,30 · x80/0,7)` × `(0,92 + 0,08 · UCS/110)` × износ.
- **МПСИ:** `E = 7,9 · (BWi/14,5)^0.9 · (F80/135)^0.45 · (1 + 0,35 · глина)` кВт·ч/т, производительность `Q = P_max/E`.
- **ШМ (Бонд):** `P80 = (W/(10·Wi) + 1/√T80)^-2`.
- **Флотация:** `ε = R∞ · (1 − 0,03/g) · (1 − 0,5 · max(0, глина − 0,05)) · (1 − e^(−kτ))`, где `k = k₀ · e^(−((P80−95)/150)²) · (1 − 1,4 · глина)`, `τ = V / Q_пульпы`.
- **Надёжность:** `λ = λ₀ · e^(4,5·(1 − h))`, износ `h` пропорционален нагрузке.
- **Борт:** `dp/dt = 0,075 · дождь − 0,15 · p`, `v = v₀ · (1 + 3p)^1.6`; время до обрушения — по методу обратной скорости (линейная регрессия 1/v).

## Разработка без Docker

```bash
python3 bozshakol/tools/devstand.py --port 8095      # http://127.0.0.1:8095/  (?tour — экскурсия,
                                                     #  ?hour=22 — ночь, ?quality=low|high, ?focus=sh-02 — крупный план)
TWINCTL_DITTO=http://127.0.0.1:8095/ditto/api/2 python3 bozshakol/tools/twinctl.py status
python3 bozshakol/grafana/build_dashboards.py        # пересобрать дашборды
python3 -m sim.main --dry-run                        # из каталога bozshakol/: один снимок всех двойников
```
