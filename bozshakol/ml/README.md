# ml/ — модели на открытых данных

| Файл | Что делает |
|---|---|
| `prepare.py` | Kaggle-флотация: 737 тыс. строк (шаг 20 с) → 4097 часов (`data/flotation-plant/flotation_hourly.csv`) |
| `train.py` | Обучает модели и пишет `models/*.json` и `models/metrics.json`; проверяет, что исполнение на чистом Python (`sim/ml.py`) совпадает со scikit-learn |
| `models/` | Готовые модели в JSON: деревья GBM, коэффициенты, 3D-сетка GeoMet. Стенду ML-библиотеки не нужны |

```bash
pip install numpy pandas scikit-learn   # только для обучения
python3 bozshakol/ml/train.py           # ~1 мин
```

## Польза: модель против простого правила

| Модель | С чем сравниваем | Модель | База | Вывод | Что меняет в двойнике |
|---|---|---|---|---|---|
| `geomet_grid` — Cu и Au блока по скважинам GeoMet | обратные расстояния (IDW), перекрёстная проверка по скважинам | R²(log Cu) 0,16 | 0,04 | лучше простой интерполяции, но содержание по положению предсказывается слабо — как в порфировых месторождениях на масштабе пробы | **влияет на модель:** содержание нового блока → шихтовка, медь |
| `geomet_hardness` — крепость по химии | среднее значение | R² 0,48 (перекр. проверка) | 0 | половина разброса крепости объяснена | **влияет на модель:** UCS и индекс Бонда блока → бурение, экскавация, ККД, энергия МПСИ |
| `flotation_silica` — SiO₂ в концентрате сейчас | последний анализ (приходит через 3 ч) | R² 0,37, MAE 0,687 | R² 0,24, MAE 0,679 | крупные отклонения ловит лучше, средняя ошибка та же; польза — оценка на 3 ч раньше | показывается в `qc-01`, превышения — в журнал; на ход модели не влияет |
| `energy_load` — нагрузка ГОК через 2 ч | «как сейчас» / «как сутки назад» | MAE 3,16 МВт | 3,65 / 5,06 МВт | на 13 % точнее «как сейчас» | показывается в `en-01` рядом с реальной нагрузкой аналога; на ход модели не влияет |
| `mwd_rocktype` — порода по MWD | самая частая порода / порода прошлого цикла | точность 0,50 | 0,23 / **0,95** | хуже картирования по прошлому циклу; тревога о смене породы бесполезна (точность 0,07) | только подсказка в `mwd-01` рядом с картированием |
| `seismic_hazard` — опасная смена | экспертная оценка шахты | AUC 0,60 на будущих сменах | 0,63 | **не лучше эксперта** на новых данных (0,77 против 0,68 только на перекрёстной проверке) | второе мнение в `sm-01`, решения по нему не принимаются |
| `geomet_recovery` — извлечение по химии | среднее значение | R² −0,10 | 0 | не предсказывается | **не подключено** |

Все метрики — на данных, которых модель не видела (разбиение по времени, пикетажу или скважинам); двойник проигрывает только эти отложенные данные. Итог честно: на работу рудника в модели влияют две модели GeoMet (содержание и крепость блоков); софтсенсор флотации и прогноз нагрузки полезны как более ранняя оценка; классификатор MWD и сейсмическая модель не лучше простых правил и показаны как подсказки, а не как основание для решений.

## MWD → порода (`mwd_rocktype`)

Данные: NGI, 15 тоннелей Норвегии, Zenodo 10358374 (CC BY 4.0, только для исследований), 4895 циклов, 10 пород. GBM на 10 классов по 32 статистикам MWD; разбиение в каждом тоннеле по пикетажу (первые 75 % — обучение, последние 25 % — тест).

| Метод | Точность на отложенных циклах |
|---|---|
| ML по MWD | 0.498 (macro-F1 0.403) |
| Самая частая порода | 0.233 |
| Порода прошлого цикла (картирование) | 0.948 |
| ML на 63 сменах породы | 0.317 (прошлый цикл — 0) |

Тревога «впереди смена породы» по ML бесполезна (точность 0.068), поэтому в двойнике `mwd-01` — подсказка рядом с картированием. Исполнение в двойнике (`sim/ml.py: gbm_proba`) сверено со scikit-learn при обучении.

## Эталон фрагментации (`fragmentation_ref`)

Дрон-фотограмметрия развала, карьер El Aljibe, Zenodo 10666378 (CC BY 4.0), взрыв B1: x50 = 179.6 мм, x80 = 334.4 мм; Розин–Раммлер n = 1.453, Swebrec b = 3.936. Модель Kuz-Ram двойника использует n = 1,35.


## Прогноз нагрузки ГОК (`energy_load`)

Данные: получасовая нагрузка пяти главных подстанций горно-обогатительного комбината, январь и июнь 2019, Zenodo 20647907 (CC BY-SA 4.0), 2928 получасов. GBM прогнозирует активную мощность через 2 ч по последним получасам, нагрузке сутки назад, времени суток и дню недели; разбиение по времени внутри месяца (последние 25 % — тест).

| Метод | MAE на отложенных данных, МВт |
|---|---|
| ML | 3.16 |
| «Как сейчас» | 3.65 |
| «Как вчера в это время» | 5.06 |

Средняя нагрузка 178.7 МВт, коэффициент заполнения графика 0.959, cos φ 0.96. Признаки сравниваются со scikit-learn в float32 (`"f32": true`) — расхождение < 10⁻⁶ МВт. Двойник `en-01` проигрывает отложенные получасы.
